Citing GenPlanner
=================

If you use GenPlanner in a publication or project, cite the software using the
repository's `CITATION.cff <https://github.com/DDonnyy/GenPlanner-lib/blob/main/CITATION.cff>`_.
GitHub's **Cite this repository** menu can export the citation in common
formats. Include the version you used, since zoning results can change between
releases.
